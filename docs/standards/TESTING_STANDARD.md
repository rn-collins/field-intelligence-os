# Testing Standard

## Required layers

- Unit tests for domain logic and validators.
- Component tests for meaningful UI states.
- Database tests for constraints, migrations and RLS.
- Integration tests for auth, storage metadata and sync boundaries.
- End-to-end tests for critical user journeys.
- Automated accessibility checks plus manual keyboard review.
- Production build verification.

## Critical journeys

1. Sign in and access only authorized workspace data.
2. Create a deployment and add a target.
3. Record interview terms and a cognition update.
4. Create a claim, link evidence and change verification status with history.
5. Add an asset link with restrictions.
6. Complete mobile Field Mode without losing a draft.

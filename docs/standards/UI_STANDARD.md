# UI and Interaction Standard

- Meet WCAG 2.2 AA target for all core workflows.
- Mobile Field Mode must be usable with one hand and within two to three taps.
- Every state has loading, empty, error, restricted and success behavior.
- Verification, consent and restriction states must be visible and never color-only.
- Avoid dense decorative dashboards that hide the next action.
- Preserve user-entered work automatically and communicate sync status.
- Use plain language before specialist terminology; explain legal/scientific states.
- Desktop supports research depth; mobile prioritizes capture and immediate decisions.
